# Bootstrap audit

## Français

ED0 contrôle la frontière d'API amont, les épingles de dépendance, la
terminologie, le harnais d'agent, le bilinguisme, les limites de lignes, le
budget de buts ouverts et les audits d'axiomes. Les sorties attendues sont
`PASS`, puis `GUARD_RESULT=PASS` et `VALIDATION_RESULT=PASS`.

## English

ED0 checks the upstream API boundary, dependency pins, terminology, agent
harness, bilingual documentation, line limits, open-goal budget, and axiom
audits. Expected output is `PASS`, then `GUARD_RESULT=PASS` and
`VALIDATION_RESULT=PASS`.
