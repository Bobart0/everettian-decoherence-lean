# GitHub settings

## Français

Après le premier push, conserver `main` par défaut, interdire les pushes
forcés et la suppression de `main`, activer GitHub Actions, vérifier le
workflow Lean, et ne créer ni tag ni release à ED0. Ne pas modifier
automatiquement la visibilité ni ces paramètres.

## English

After the first push, retain `main` as default, prohibit force pushes and
deletion of `main`, enable GitHub Actions, verify the Lean workflow, and
create no tag or release at ED0. Do not automatically change visibility or
these settings.
