# Decision log

## Français

- D0001 — Separate downstream repository : isoler le programme approximatif et
  dynamique du dépôt exact.
- D0002 — Stable upstream facades only : empêcher les dépendances internes.
- D0003 — Zero open-goal budget : partir d'un socle sans dette formelle.
- D0004 — No scientific roadmap at bootstrap : soumettre ED1 à un audit
  d'architecture séparé.

## English

- D0001 — Separate downstream repository: isolate the approximate and dynamic
  program from the exact repository.
- D0002 — Stable upstream facades only: prevent internal dependencies.
- D0003 — Zero open-goal budget: begin without formal debt.
- D0004 — No scientific roadmap at bootstrap: subject ED1 to a separate
  architecture audit.
