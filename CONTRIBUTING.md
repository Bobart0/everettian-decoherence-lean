# Contribution

## Français

Les incréments sont atomiques. Lire les `AGENTS.md` applicables, vérifier les
signatures amont, compiler la cible, lancer build et gardes, puis inspecter le
diff. Toute prémisse exige ses témoins. Aucun push forcé, aucune mise à jour
implicite de dépendance et aucune revendication physique non formalisée.

## English

Increments are atomic. Read applicable `AGENTS.md` files, verify upstream
signatures, compile the target, run the build and guards, then inspect the
diff. Every premise needs witnesses. No force push, implicit dependency update,
or unformalized physical claim.
